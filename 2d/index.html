FORGEWORLD 2D

톱다운 공정 프로토타입 — 철 광석에서 강판까지 6단계

규칙: 모든 레시피는 처음부터 Tab 도감에 공개. 막는 건 재료·온도·동력뿐.
체인: 파쇄 → 선별 → 소결(900°C) → 제련(1500°C, 석탄) → 정련(1600°C+송풍) → 압연. 초반엔 괴철로(목탄+풀무)로 철판을 만들어요.
동력: 손 크랭크(마우스 올리고 좌클릭 유지)나 증기기관을 회전축으로 연결. 모자라면 느려져요.
온도: 목재 600 · 목탄 1000 · 석탄 1500°C. 장치 한계를 넘기면 과열로 망가져요. 석탄은 북동쪽 황야에만.
마모: 쓰면 닳고 0이면 고장. 기계 창에서 수리. 뜨거운 기계 옆에 오래 있으면 열 노출.
