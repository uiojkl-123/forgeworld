# FORGEWORLD — 게임 기획서 v0.4

> 작성일 2026-10-16 · v0.4: 2D 톱다운 프로토타입 추가, UE5는 Windows에서 추후
> 이 문서는 "헌법(§1~§2)"과 "설계(§3~§9)"와 "실행(§10~§12)"으로 나뉜다. 헌법은 바꾸지 않는다. 설계는 토론한다. 실행은 매 마일스톤마다 갱신한다.

---

## 1. 한 줄 콘셉트

**"탐험 → 손노가다 → 자동화 → 관리 → 종결 자동화"**
플레이어는 바이옴으로 나뉜 버려진 행성에서 자원을 캐고, 공정(열·기계·화학·전기)을 직접 조립해 공장을 키운다. 기계는 마모되고 고장 나지만, 재료와 이해가 쌓이면 "손바닥만 한 장치가 공장 한 동을 대체하는" 종결 자동화에 도달한다. 그리고 그 끝에서 이 행성 자체가 거대한 자동화 기계의 산출물이었음을 알게 된다.

- 장르: 1인칭 오픈월드 자동화·제작 (건설 시 자유 카메라). 생존은 환경 위험만
- 목표 플레이 타임: 50시간+ (메인 루프 완주 기준)
- 플랫폼: PC (Mac Apple Silicon 포함) · 싱글 우선, 협동은 구조만 열어둠
- 엔진: Unreal Engine 5 (§11)

## 2. 헌법 — 바꾸지 않는 원칙

1. **자동화는 도구다.** 목적이 아니다. 자동화는 "더 많이, 더 오래, 더 안정적으로"를 위한 확장 버튼이고, 항상 손노동 *뒤에* 등장한다.
2. **모든 조합법은 처음부터 열려 있다.** 설계도 언락 없음. 기술 트리 없음. 막는 것은 오직 재료·환경·조건(온도, 압력, 강도, 동력)이다. "아는가"가 아니라 "해낼 수 있는가".
3. **'정제기'는 없다.** 기계가 아니라 공정(Process)이 단위다. 파쇄·선별·가열·반응·냉각·압축이 각각 다른 장치, 다른 조건, 다른 실패 방식을 가진다.
4. **같은 공정, 다른 크기.** 초반엔 방 하나, 후반엔 큐브 하나. 소형화는 보상이 아니라 재료와 정밀도가 허락한 물리적 결과다.
5. **자연은 시스템이 아니라 조건이다.** 생태계 시뮬레이션 없음. 바이옴은 온도·습도·고도·독성·자원 분포로만 공정에 영향을 준다. 자연은 배경이자 퍼즐.
6. **인공 구조물은 재료를 준다, 설계도를 주지 않는다.** 직접 재현이 어려운 기성 부품·소재를 "발견"한다. 레시피는 이미 알고 있었다.
7. **청사진은 저장 도구다.** 플레이어가 직접 만든 구조·공정만 저장·복제한다. 게임이 주는 청사진은 없다.
8. **환경이 기술을 강요한다.** 석탄 바이옴이 열 공정을 열고, 철이 고압을 열고, 극한 바이옴이 고급 소재를 요구한다. "이제 이건 손으로 못 한다"가 유일한 진행 트리거.
9. **설명하지 말고 드러내라.** 스토리는 구조물·지형·패턴으로만 암시한다. 텍스트 덤프 없음.
10. **관리 피로는 반드시 극복 가능해야 한다.** 초반의 마모·고장은 긴장이고, 후반의 자가 수리·무정비는 플레이어가 *벌어낸* 평화다. 영원한 잡일은 없다.

## 4. 핵심 기둥 (Pillars)

1. **이해의 게임** — 정답을 외우는 게 아니라 법칙을 이해해서 설계한다. 실험 실패도 정보다.
2. **물리적 스케일의 성장** — 진행은 숫자가 아니라 "크기와 밀도"로 보인다. 같은 공정이 작아지고 조용해진다.
3. **살아있는 공장, 죽어있는 세계** — 공장은 돌고 마모되고 고쳐진다. 세계는 버려져 있고 고요하다. 대비가 분위기다.
4. **벌어낸 평화** — 종결 상태는 "내가 안 봐도 되는 공장". 거기까지가 50시간이다.

## 5. 월드

### 5.1 구조
- 랜덤 시드 기반 오픈월드. 바이옴 단위로 명확히 구분(경계가 보임).
- 바이옴은 기후·지형·자원 분포·공정 조건만 다르다. 몹·생태계 없음.
- 바이옴 위에 인공 구조물(이전 세대의 서브모듈)이 흩어져 있다.
- 세계관 최소 설정: "지구가 아니다. 물리가 살짝 다르다. 누군가 개척한 적 있지만 지금은 비어 있다." 설명은 여기까지. 나머지는 §9 반전.

### 5.2 바이옴 초안 (5개 + 코어)

| 바이옴 | 조건 | 고유 자원 | 위험/디버프 | 강요하는 기술 |
|---|---|---|---|---|
| 온대 숲 (시작) | 온화, 습도 중 | 목재, 돌, 저품위 철, 점토 | 거의 없음. 습도로 느린 부식 | 손노동, 목탄, 수동 동력 |
| 석탄 황야 | 건조, 먼지 | 석탄, 유황, 중품위 철 | 분진 → 기계 마모 가속, 가시거리 | 열 공정 안정화, 증기 동력 |
| 화산 지대 | 고온(지표 80°C+), 지열 | 구리, 현무암, 지열 증기, 흑요석 | 과열 → 냉각 없이는 기계 정지, 용암 | 냉각 공정, 내열 소재, 지열 발전 |
| 냉동 고원 | 극저온, 고고도(저압) | 희토류, 얼음(물), 순수 결정 | 저온 → 유체 동결, 배터리 효율↓ | 단열, 저압 공정(진공 전 단계), 보온 |
| 독성 습지 | 습도 극, 산성 | 유기 슬러지, 인, 촉매 광물 | 부식 → 마모 3배, 유독 가스 | 화학 공정, 내식 소재, 정화 |
| (후반) 코어 지대 | 비자연적 규칙 지형 | 안정화 코어 파편, 완전 소재 | 행성 시스템의 간섭 | 집약 장치, 엔딩 선택 |

> 바이옴 수는 5개가 1인 개발 상한. 여기서 더 늘리지 않는다.

### 5.3 인공 구조물
- 정체: 이전 세대의 자동화 노드. 고장 나서 방치됨. "폐허인데 너무 체계적"이 힌트.
- 종류: 폐채굴장(소), 정제 플랜트(중), 연구 시설(대), 중계기(코어 힌트).
- 보상 원칙(헌법 6): 초고밀도 베어링, 무결점 세라믹, 안정화 코어, 소형 반응기 파츠 같은 **재현 불가 소재·부품**. 수량 제한. 레시피 언락은 절대 없음.
- 구조물 안에는 작동 중인 기계가 한두 대 남아 있어도 된다. 플레이어가 보고 배우는 "예시 공장".

## 6. 공정 시스템 (핵심)

### 6.1 공정의 정의
공정 = `입력 재료 + 조건 → 출력 + 부산물 + 마모`. 조건은 다음 다섯 가지 수치로 통일한다.

| 조건 | 단위 | 올리는 방법 | 실패 양상 |
|---|---|---|---|
| 온도 | °C | 연료, 전열, 지열, 집열 | 미달: 반응 안 함 / 초과: 소재 변성, 장치 손상 |
| 압력 | bar (음압 포함) | 압축기, 밀폐, 고도 | 누설, 파열 |
| 동력 | kW (회전/전기) | 손, 수차, 증기, 전기 | 정지, 축 파손 |
| 정밀도 | 등급 1~5 | 장치 세대, 안정화 부품 | 불량률↑, 부산물↑ |
| 시간 | s | — | 느림 자체가 비용 |

### 6.2 공정 4계열

| 계열 | 장치 예 | 성격 | 고유 리스크 |
|---|---|---|---|
| 열 (Thermal) | 화로, 소성로, 용광로, 고온 반응기 | 연료·온도 관리 | 과열, 연료 고갈, 화재 |
| 기계 (Mechanical) | 분쇄기, 선별기, 프레스, 회전축 | 동력 전달·정렬 | 마모, 축 파손, 정렬 오차 |
| 화학 (Chemical) | 반응조, 증류탑, 침전조, 촉매기 | 부산물·독성 | 누출, 오염, 폭주 반응 |
| 전기 (Electrical) | 아크로, 전해조, 전자 정제 | 고출력·안정 | 과부하, 정전, 고가 |

### 6.3 재료 속성 모델
모든 재료는 데이터 테이블 한 장으로 정의한다: `녹는점 / 강도 / 반응성 / 내식성 / 밀도 / 전도율`. 공정 조건 판정과 장치 내구 판정이 전부 이 표를 읽는다. 새 재료 추가 = 행 하나 추가.

### 6.4 대표 체인 (버티컬 슬라이스 범위)
```
철 광석 → [분쇄: 기계, 2kW] → 철 분말
       → [선별: 기계, 1kW] → 정광 + 맥석(부산물)
       → [소성: 열, 900°C] → 소결광
       → [제련: 열, 1500°C, 목탄/석탄] → 선철
       → [정련: 열+압력, 1600°C, 공기 주입] → 강철
       → [압연: 기계, 15kW, 정밀도 2] → 강판 / 강봉
```
초반엔 각 단계가 별도의 큰 장치 + 손 운반. 중반엔 컨베이어·파이프·축으로 연결. 후반엔 "제강 모듈" 큐브 하나.

## 7. 진행 — 에너지 밀도와 세대

### 7.1 기술 트리 대신 '에너지 밀도 계단'
진행을 제어하는 변수는 하나다: **플레이어가 안정적으로 다룰 수 있는 에너지 밀도.**

| 단계 | 동력원 | 도달 온도 | 열리는 것 | 강요하는 바이옴 |
|---|---|---|---|---|
| 0 손 | 인력 크랭크 | ~600°C(목탄) | 분쇄, 화로 | 시작 숲 |
| 1 생물 | 목탄, 수차 | ~900°C | 소성, 저압 증기 | 숲 |
| 2 석탄 | 증기기관 | ~1500°C | 제련, 압축기, 1차 자동화 | 석탄 황야 |
| 3 철강 | 고압 증기, 지열 | ~1800°C, 10bar | 정련, 고압 반응, 파이프망 | 화산 |
| 4 전기 | 발전기, 전력망 | 아크 3000°C | 전해, 정밀도 4, 소형화 1차 | 냉동/습지 |
| 5 집약 | 안정화 코어 | 조건 자유 | 큐브 장치, 자가 수리, 무정비 | 코어 지대 |

### 7.2 사이즈 세대
- **Gen 1 (방)**: 공정 1개 = 3×3×3m 이상. 외부 연료·동력. 손으로 유지보수.
- **Gen 2 (블록)**: 공정 1개 = 1×1×1m 모듈. 표준 입출력 포트. 청사진 본격 사용.
- **Gen 3 (큐브)**: 공정 5~6개 = 큐브 1개. 내부 조건 자동 관리. 자가 수리.
Gen 전환 조건은 "재료 등급 + 정밀도 등급"만. 언락 없음(헌법 2, 4).

동력 전달도 세대를 따른다: Gen 1~2는 회전축·벨트·증기관을 실제로 배치해야 하고(정렬·길이·마모가 설계 문제), Gen 3 전기부터는 전력선처럼 범위 연결로 추상화된다. "물리적 배선 지옥에서 벗어나는 것" 자체가 후반 보상이다.

## 8. 관리·불안정 시스템

- **마모**: 모든 장치에 내구도. 소모 속도 = 기본 × 부하 × 환경 계수(습도·분진·부식) ÷ 소재 등급.
- **고장**: 내구 하한에서 확률 발생. 고장 유형은 계열별(§6.2 고유 리스크). 고장은 라인을 멈추고, 가끔 부산물을 쏟는다.
- **수리**: 초반 손 수리(부품 소모). 중반 예비 부품 자동 교체. 후반 수리 드론 → 자가 수리 소재.
- **환경 영향**: 화학 공정은 오염 수치를 올리고, 오염은 주변 장치 마모를 올린다. 정화 공정으로 상쇄.
- **플레이어 환경 위험**: 허기 없음. 바이옴별 위험(고온·극저온·독가스·분진)이 체력을 깎고, 보호복·냉각팩·정화 마스크 같은 장비로 상쇄. 장비도 마모된다(§8 마모 규칙 공유).
- **종결 조건**: 평균 가동률 99%+, 수동 개입 0인 상태 24시간(게임 내) 유지 → "무인 공장" 달성.
- **절대 규칙**: 관리 부담은 단조 감소해야 한다. 후반에 잡일이 늘면 설계 실패.

## 9. 스토리 · 반전 · 엔딩

- **표면**: 개척됐다가 버려진 외계 행성.
- **진실**: 행성 자체가 초거대 자동화 시스템의 산출물. 바이옴 = 공정 단계, 산맥 = 냉각 핀, 심해 = 폐열 배출부, 코어 = 중앙 장치. 구조물은 이전 세대의 서브모듈.
- **드러내는 순서** (설명 금지):
  1. 초반: 아무 의문 없음.
  2. 중반: 구조물이 "너무 의도적". 바이옴 경계가 지나치게 반듯하다는 걸 지도에서 발견.
  3. 후반: 행성 규모 패턴(자원 분포가 균형 잡힌 입력값처럼 보임). 중계기 구조물이 코어 방향을 가리킴.
  4. 엔딩 근처: 플레이어의 공장을 행성 네트워크에 접속할 수 있게 됨.
- **엔딩 3택**: 유지(관리자가 된다) / 재설계(새 시드, New Game+) / 종료(모든 것이 멈춘다).
- 플레이어 정체성 전환: "개척자"에서 "이 시스템의 다음 설계자"로.

## 10. 톤 · 아트 · 사운드

- 비주얼: 카툰+인더스트리얼. 사실적 라이팅 위에 단순한 형태. 재질은 금속·녹·그을음 중심.
- UE5 활용: Lumen으로 용광로·용암·아크 광원의 분위기, Nanite로 밀집한 공장 지오메트리. 캐릭터·몹에 리소스 쓰지 않는다.
- 분위기: 노가다인데 힐링. 돌아가는 공장을 멍하니 볼 수 있어야 한다.
- 사운드: 기계 ASMR이 1순위 콘텐츠. 공정 계열별 고유 소음, 마모되면 소리가 변한다(고장 예고를 소리로).

## 11. 기술 · 엔진

### 11.1 엔진 판단
- **Unreal Engine 5.5+** 확정 방향. (2026-10-16 결정: Mac에선 진행하지 않고 추후 Windows PC에서. 그때까지 웹 프로토타입으로 설계 검증) 이유: 그래픽 목표(무거운 비주얼), 1인칭·대규모 월드 도구가 내장, Lumen/Nanite가 공장 장면에 적합.
- Mac(Apple Silicon)에서 에디터·패키징 모두 가능. Nanite/Lumen도 Metal에서 동작. 단 PC 대비 느리고 메모리 32GB 이상이 편하다. 최종 빌드 검증은 Windows에서도 한 번 필요.
- 언어: 핵심 시뮬레이션(공정·마모·물류 틱)은 C++, 콘텐츠·UI·연출은 Blueprint. 데이터(재료·공정)는 DataTable/CSV.
- 네트워크: 싱글 출시지만 공정·물류·인벤토리 상태는 서버 권위(리슨 서버) 구조로 작성. 협동 추가 시 재작성을 피하기 위함. 클라이언트 예측은 하지 않는다.
- 시점: 1인칭 캐릭터 + 건설 모드 전용 자유 카메라(Pawn 전환).
- 지형: 월드 파티션 + 랜덤 시드 기반 생성. 보셀 지형은 하지 않는다(마인크래프트식 파괴 지형은 스코프 밖). 채굴은 노드 단위.

### 11.2 핵심 기술 리스크 (먼저 검증할 것)
1. 수천 개 장치의 공정 틱을 60fps 안에 돌리기 → 틱 분산·배치 시뮬레이션 설계.
2. 컨베이어·파이프 위 수만 개 아이템 렌더 → 인스턴싱, 아이템은 데이터로만 두고 보이는 구간만 그린다.
3. 세이브 크기와 로드 시간.
4. 프로시저럴 바이옴 품질 — "레벨디자인이 잘 돼 있어야 함"과 랜덤 생성은 긴장 관계. 손으로 만든 구조물 프리팹 + 랜덤 배치로 타협.

**P0 상태 (2026-10-16)**: `index.html`에 구현 완료. 들어간 것 — 철강 체인 6단계(파쇄→선별→소결→제련→정련→압연) + 부트스트랩용 괴철로, 연료별 온도(목재 600 / 목탄 1000 / 석탄 1500)와 장치 한계·과열 마모, 송풍 보너스(괴철로·전로), 회전축 동력(손 크랭크 3kW / 증기기관 20kW, 부족하면 비례 감속), 마모·고장·수리, 전부 공개된 레시피 도감, 석탄 황야 바이옴(시작점에서 150m), 열 노출 환경 피해(허기 없음). 브라우저 시뮬레이션으로 전 체인·과열 고장·세이브 왕복 검증. 첫 데모는 `docs/prototype-v0-satisfactory-lite.html`에 보관.

**P0-2D (2026-10-16)**: UE5는 나중에 Windows에서 진행하기로 하고, 같은 공정 모델을 `2d/index.html`에 톱다운 2D(Canvas, 의존성 0)로 다시 구현. 손맛에 집중: 타격 파티클·화면 흔들림·떠오르는 획득 텍스트, 파일 없이 WebAudio로 합성한 효과음(채굴·크랭크·점화·고장·목표 달성)과 기계 험·불 소리 앰비언스, 밤 조명과 열원 글로우, 미니맵. 기계는 2×2 그리드, 설치 전 나무·바위를 치워야 함. 회전축·컨베이어는 기계 간 링크(타일 벨트 아님).

**P0에서 확인한 질문** (위 결과로 1·2·3은 긍정, 4·5는 추후 외부 테스터로 확인):
